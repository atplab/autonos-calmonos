# autonos-calmonos

## Installation mobile

Le site est une Progressive Web App (PWA). Depuis Microsoft Edge ou Chrome sur
Android, ouvrir le menu du navigateur puis choisir **Installer l’application**
ou **Ajouter à l’écran d’accueil**. Sur iPhone et iPad, utiliser le bouton
**Partager**, puis **Sur l’écran d’accueil** dans Safari.

L’application fonctionne également hors connexion après sa première ouverture
sur une adresse HTTPS.

## APK Android

Le projet Android se trouve dans [android-app](./android-app). Une action
GitHub génère automatiquement un APK de débogage à chaque modification de ce
dossier. Dans GitHub, ouvrir l’onglet **Actions**, sélectionner **Build
Android APK**, puis télécharger l’artefact
`autonos-calmonos-android` à la fin de l’exécution.
